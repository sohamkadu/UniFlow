# 📖 Overview

UniFlow is a modern cross-chain USDC dashboard that simplifies digital asset management.

Instead of manually bridging assets and switching networks, UniFlow provides users with a unified balance experience powered by Circle's App Kit.

Users can:

- 💰 View a unified USDC balance
- 🌉 Deposit USDC from supported chains
- ⚡ Spend from a single balance
- 🔄 Track activity
- 🎯 Enjoy a clean and beginner-friendly interface

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/UniFlow.git
```

Go inside the project

```bash
cd UniFlow
```

Install dependencies

```bash
npm install
```

Configure environment variables

Create a `.env` file using the provided example.

Example:

```env
VITE_APPKIT_CLIENT_KEY=YOUR_KEY
VITE_APPKIT_ENTITY_SECRET=YOUR_SECRET
```

Start development server

```bash
npm run dev
```

Build production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```

# 💡 Why UniFlow?

Managing assets across multiple chains can be confusing.

UniFlow removes unnecessary complexity by providing one seamless experience for managing USDC across supported networks.

Our goal is to make cross-chain payments feel as simple as using a traditional banking app.
